# Prajakta AI Portfolio

A responsive, interactive portfolio website for an AI/ML Engineer and AI Teacher/Trainer.

## Run
Open `index.html` in any modern browser.

## Customize
- Replace the placeholder email in `index.html`.
- Replace LinkedIn/GitHub links with your profiles.
- Add your resume PDF to this folder and add a Resume button if desired.
- Edit project descriptions, education and experience as your details evolve.

No build step is required.
